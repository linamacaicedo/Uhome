# UHome

UHome is a student housing platform designed to help university students find housing in a simpler, safer and more informed way.

Unlike traditional housing platforms that only display listings, UHome focuses on helping students make better decisions by considering factors such as price, location, proximity to their university, available amenities, reviews and the characteristics of the surrounding area.

## Project Structure

This repository contains both the frontend and backend of the project.

- `frontend/` – User interface of the UHome platform.
- `backend/` – Backend developed with NestJS and TypeORM.

## Main Features

- User registration and profile management
- Property search and filtering
- Property details and amenities
- Student reviews and ratings
- Student preferences
- Area and student environment information
